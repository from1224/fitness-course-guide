通用动作速查

以下为公开教学归纳的通用提示与原创比喻，不是谭成义原话，也不表示某一课程一定包含该动作。动作保持可控，出现疼痛就停；非个性化训练处方。

卧推

  1. 摆姿：双脚踩稳，肩背和臀部贴凳
  2. 比喻：像推开上方的门，稳推慢回
  3. 注意：臀部别离凳，慢放不砸胸
查看公开来源ACE Exercise Library 教程

上斜哑铃卧推

  1. 摆姿：背靠斜凳，脚踩稳，手腕放正
  2. 比喻：像把天花板推远，慢慢收回
  3. 注意：别过度挺腰，手腕别向后折
查看公开来源ACE Exercise Library 教程

辅助双杠臂屈伸

  1. 摆姿：握稳扶手，膝部放稳辅助垫
  2. 比喻：把扶手向下压，让身体升起
  3. 注意：别追深度；肩部疼痛就停
查看公开来源HKU exercise handout 教程

普通哑铃侧平举

  1. 摆姿：站稳收腹，双肘微弯
  2. 比喻：像缓缓展开翅膀，抬到约肩高
  3. 注意：别甩身借力，也别做倒水手势
查看公开来源ACE Exercise Library 教程

高位下拉

  1. 摆姿：压垫固定大腿，坐稳收腹
  2. 比喻：肘尖像拉帘绳，向下靠近肋侧
  3. 注意：拉向胸前，别后仰甩动身体
查看公开来源ACE Exercise Library 教程

坐姿器械划船

  1. 摆姿：双脚踩稳，躯干立稳
  2. 比喻：双肘像拉抽屉，沿身侧向后滑
  3. 注意：别后仰扯动，回程也慢慢放
查看公开来源ACE Exercise Library 教程

徒手深蹲

  1. 摆姿：脚掌踩稳，膝盖朝脚尖方向
  2. 比喻：像坐下再起立，脚掌稳压地面
  3. 注意：别为蹲深抬脚跟或弓背
查看公开来源ACE Exercise Library 教程

罗马尼亚硬拉

  1. 摆姿：膝盖微弯，重量贴近大腿
  2. 比喻：屁股向后关门，重量贴腿滑下
  3. 注意：背形稳不住就停，别追着地
